# Cecilia Parlatore — website rebuild

Static site prepared for GitHub Pages.

## Preview locally
Open `index.html` in a browser.

## Before launch
1. Review all text and publication metadata.
2. Add a current portrait if desired.
3. Replace/add direct paper, BibTeX, slide, video and reading-group links.
4. Upload these files to the root of a GitHub repository.
5. Enable GitHub Pages and set the custom domain to `ceciliaparlatore.com`.
6. Only after the GitHub preview is approved, replace the Namecheap masked redirects with GitHub Pages DNS records.

The existing Weebly site does not need to be changed during the build/review stage.
